# Spec: Fejlett elemzési funkciók

## Cél
Az elemzési felület bővítése mélyebb pozícióelemzési eszközökkel.

## Tervezett funkciók
- Annotation rendszer (?, !, ?!, !? jelölők lépésekhez)
- PGN export (letöltés gomb)
- Engine depth / time control beállítás
- Értékelési grafikon a játszma menetéhez

## Elfogadási kritériumok
- A felhasználó minden lépéshez tud jelölőt rendelni
- A PGN exportban megjelennek az annotációk
- Az engine beállítások perzisztensek (localStorage)
